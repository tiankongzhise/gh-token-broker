能力含义速查

写入分支
允许 agent 修改指定分支上的内容。可以通过 branch pattern 限制到 agent/*，并排除 main/release 等重要分支。
删除分支
删除是独立能力，不因“能写分支”自动允许。可限制为 agent/*、短期、已合并或超过指定时间的分支。
Pull Request
创建/更新 PR 与 merge PR 是不同能力。merge 可以要求 checks 和 review 满足。
不可安全执行
如果系统不能保证限制不被绕过，对应能力应显示不可用或拒绝，而不是用更宽权限代替。
